# Your work goes here

This directory is empty on purpose. Everything you write for the exercise —
providers, wrappers, screens, styles, whatever shape it ends up taking — goes
in `app/src/kaafil/`, and you can lay it out however you like.

Nothing else in `app/` has been started for you. The CRM you can see at
<http://localhost:5173> is finished and is not part of the exercise: treat
`app/src/crm/`, `app/src/styles/crm.css` and `server/` as somebody else's code
that already shipped. You may read them, and you will need to in order to hang
your work off the right screens, but you should not need to rewrite them.

Start at [`docs/01-the-exercise.md`](../../../docs/01-the-exercise.md).
